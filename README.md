# Ghana Payslip Calculator

Streamlit app that works out monthly gross pay, SSNIT, PAYE and net pay in Ghana.

- PAYE: monthly resident bands from the Income Tax (Amendment) Act, 2026 (Act 1178), effective 1 September 2026.
- SSNIT: employee 5.5%, employer 13% of basic salary; maximum insurable earnings GH₵69,000/month (2026).
- Allowances and deductions can each be a GH₵ amount or a percentage of basic salary.

Run locally:

```
pip install -r requirements.txt
streamlit run app.py
```

Figures are estimates; check against your payslip or with GRA.
